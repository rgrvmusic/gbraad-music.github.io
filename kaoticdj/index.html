About KaoticDJ

KaoticDJ - Dual Deck Controller

Web-based dual deck DJ application with WebMIDI support

Connects to Korg KaossDJ and other MIDI controllers

Real-time audio mixing with EQ, filter, and crossfader

MIDI Learn mode for custom controller mapping

Uses: Web Audio API, WebMIDI API

Created by Gerard Braad <me@gbraad.nl>
